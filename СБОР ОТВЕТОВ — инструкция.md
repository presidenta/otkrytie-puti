# Как видеть все ответы участников

Приложение работает без сервера, поэтому ответы отправляются в **вашу Google Таблицу**.
Таблица принадлежит вашему Google-аккаунту: видите её только вы, пока сами кому-то не откроете доступ.

Настройка занимает 5–7 минут и делается **один раз**.

---

## Шаг 1. Создайте таблицу

1. Откройте https://sheets.new — создастся пустая таблица.
2. Назовите её, например, **«Открытие Пути — ответы»**.

## Шаг 2. Откройте редактор скриптов

В меню таблицы: **Расширения → Apps Script**.
Откроется новая вкладка с файлом `Код.gs` и текстом внутри.

## Шаг 3. Вставьте код

Удалите всё, что там есть, и вставьте это целиком:

```javascript
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    var d = JSON.parse(e.postData.contents);

    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        'Дата', 'Время', 'Язык', 'Имя', 'Контакт',
        'Ведущий вектор', 'Баллы', 'Дополняющий вектор', 'Баллы', 'Максимум',
        'Все векторы', 'Готовность %', 'Нужно ч/день', 'Готов ч/день',
        'Мечта 1', 'Мечта 2', 'Мечта 3',
        'Цена мечты', 'Личный вклад', 'Уровень дохода',
        'Состояние сейчас', 'Паттерн саботажа', 'Копинг под давлением', 'Готов отдать',
        'Все ответы'
      ]);
      sheet.setFrozenRows(1);
      sheet.getRange(1, 1, 1, 25).setFontWeight('bold');
    }

    var full = (d.answers || []).map(function (a) {
      return 'В' + a.id + ': ' + a.picks.filter(String).join(' // ');
    }).join('\n');

    sheet.appendRow([
      d.date, new Date(), d.lang, d.name, d.contact,
      d.lead, d.leadScore, d.sub, d.subScore, d.maxScore,
      d.scores, d.readiness, d.needHours, d.giveHours,
      d.dream1, d.dream2, d.dream3,
      d.price, d.commit, d.income,
      d.state, d.sabotage, d.coping, d.tradeoff,
      full
    ]);

    return ContentService.createTextOutput('ok');
  } finally {
    lock.releaseLock();
  }
}
```

Нажмите значок дискеты — **Сохранить**.

## Шаг 4. Опубликуйте скрипт

1. Справа вверху: **Развернуть → Новое развёртывание**.
2. Нажмите шестерёнку рядом с «Тип» и выберите **Веб-приложение**.
3. Заполните:
   - **Описание** — «Открытие Пути»
   - **Запуск от имени** — **Я** (ваш адрес)
   - **У кого есть доступ** — **Все**
4. Нажмите **Развернуть**.
5. Google попросит разрешение — **Разрешить доступ**, выберите свой аккаунт.
   Если появится экран «Google не проверил это приложение»: **Дополнительные настройки → Перейти к «Без названия» (небезопасно)**. Это ваш собственный скрипт, предупреждение стандартное для личных скриптов.
6. Скопируйте **URL веб-приложения**. Он выглядит так:
   `https://script.google.com/macros/s/AKfycb.../exec`

> ⚠️ «У кого есть доступ: Все» означает, что по этому адресу можно **отправить** данные. Читать таблицу посторонние не могут — она остаётся приватной.

## Шаг 5. Вставьте адрес в приложение

Откройте [js/config.js](js/config.js), найдите блок `submit` и вставьте адрес в кавычки:

```javascript
submit: {
  url: 'https://script.google.com/macros/s/AKfycb.../exec',
  askContact: true
},
```

Сохраните файл.

## Шаг 6. Обновите сайт

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
git add -A
git commit -m "подключил сбор ответов"
git push
```

Через минуту сайт обновится. Пройдите анкету сами — в таблице появится первая строка.

## Что попадает в таблицу

Одна строка = один пройденный тест, 25 колонок:

| Колонка | Содержимое |
|---|---|
| Дата, Время | когда прошёл |
| Язык | ru или ua |
| Имя, Контакт | что человек ввёл на старте |
| Ведущий / Дополняющий вектор + баллы | психотип |
| Все векторы | баллы по всем восьми, одной строкой |
| Готовность % | индекс готовности |
| Мечта 1–3 | три ответа про достижения дословно |
| Цена мечты, Личный вклад, Уровень дохода | ответы на финальные вопросы |
| Состояние, Саботаж, Копинг, Готов отдать | расширенный профиль |
| **Все ответы** | каждый выбор по всем 20 вопросам, дословно, с номерами |

В последней колонке видно всё до единого выбора — по ней можно разбирать человека вручную.

## Что важно знать

**Пока адрес не вставлен**, приложение ничего никуда не отправляет и честно пишет об этом участнику на стартовом экране: «Все данные остаются в этом браузере». Как только адрес появится, текст автоматически меняется на «ответы будут переданы организатору проекта». Участник всегда видит правду — это и порядочно, и требуется законом о персональных данных.

**Если у участника пропал интернет**, результат кладётся в очередь в его браузере и уходит сам, когда человек в следующий раз откроет страницу. Ответ не теряется.

**Поле контакта** появляется на старте только когда сбор включён. Если оно не нужно — поставьте `askContact: false` в конфиге.

**Удаление данных.** Участник вправе попросить удалить свой ответ — просто удалите его строку в таблице.

## Альтернативы, если Google не подходит

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Google Таблица** ← сейчас | бесплатно, данные ваши, готовая админка | нужна разовая настройка |
| Airtable, Notion | красивее интерфейс | лимиты бесплатного тарифа |
| Свой сервер + база | полный контроль | нужен разработчик и оплата хостинга |
| Только кнопка «Скопировать отчёт» | ничего не настраивать | участник может не прислать |

Скажите, если захотите другой вариант — движок отправки универсальный, меняется только адрес.
