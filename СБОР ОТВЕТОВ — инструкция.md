# Как видеть все ответы участников

Приложение работает без сервера, поэтому ответы отправляются в **вашу Google Таблицу**.
Таблица принадлежит вашему Google-аккаунту: видите её только вы, пока сами кому-то не откроете доступ.

Настройка занимает 5–7 минут и делается **один раз**.

---

## Шаг 1. Создайте таблицу

1. Откройте https://sheets.new — создастся пустая таблица.
2. Назовите её, например, **«Открытие Пути — ответы»**.

## Шаг 2. Откройте редактор скриптов

В меню таблицы: **Расширения → Apps Script**.
Откроется новая вкладка с файлом `Код.gs` и текстом внутри.

## Шаг 3. Вставьте код

Удалите всё, что там есть, и вставьте это целиком:

```javascript
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    var d = JSON.parse(e.postData.contents);

    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        'Дата', 'Время', 'Язык', 'Имя', 'Telegram', 'Telegram ID',
        'Согласие', 'Когда согласился',
        'Ведущий вектор', 'Баллы', 'Дополняющий вектор', 'Баллы', 'Максимум',
        'Все векторы', 'Готовность %', 'Нужно ч/день', 'Готов ч/день',
        'Мечта 1', 'Мечта 2', 'Мечта 3',
        'Цена мечты', 'Личный вклад', 'Уровень дохода',
        'Состояние сейчас', 'Паттерн саботажа', 'Копинг под давлением', 'Готов отдать',
        'Все ответы'
      ]);
      sheet.setFrozenRows(1);
      sheet.getRange(1, 1, 1, 28).setFontWeight('bold');
    }

    var full = (d.answers || []).map(function (a) {
      return 'В' + a.id + ': ' + a.picks.filter(String).join(' // ');
    }).join('\n');

    sheet.appendRow([
      d.date, new Date(), d.lang, d.name, d.contact, d.tgId,
      d.consent, d.consentAt,
      d.lead, d.leadScore, d.sub, d.subScore, d.maxScore,
      d.scores, d.readiness, d.needHours, d.giveHours,
      d.dream1, d.dream2, d.dream3,
      d.price, d.commit, d.income,
      d.state, d.sabotage, d.coping, d.tradeoff,
      full
    ]);

    notifyTelegram(d);
    return ContentService.createTextOutput('ok');
  } finally {
    lock.releaseLock();
  }
}

/* Уведомление в Telegram. Работает, только если заполнены BOT_TOKEN и CHAT_ID.
   Токен лежит здесь, на серверах Google, и в браузер участника не попадает. */
var BOT_TOKEN = '';   // сюда токен от @BotFather
var CHAT_ID   = '';   // сюда ваш числовой id от @userinfobot

function notifyTelegram(d) {
  if (!BOT_TOKEN || !CHAT_ID) return;
  var who = d.tgUser ? '@' + d.tgUser : (d.contact || d.name || 'без контакта');
  var text =
    '🜚 Новый пройденный тест\n' +
    '👤 ' + (d.name || '—') + '  ' + who + '\n' +
    '🧭 ' + d.lead + ' (' + d.leadScore + ') + ' + d.sub + ' (' + d.subScore + ')\n' +
    '⚡ Готовность: ' + d.readiness + '%\n' +
    '🔥 ' + d.state + ' / ' + d.sabotage + '\n' +
    '🥇 ' + d.dream1;
  UrlFetchApp.fetch('https://api.telegram.org/bot' + BOT_TOKEN + '/sendMessage', {
    method: 'post',
    payload: { chat_id: CHAT_ID, text: text },
    muteHttpExceptions: true
  });
}
```

Нажмите значок дискеты — **Сохранить**.

## Шаг 4. Опубликуйте скрипт

1. Справа вверху: **Развернуть → Новое развёртывание**.
2. Нажмите шестерёнку рядом с «Тип» и выберите **Веб-приложение**.
3. Заполните:
   - **Описание** — «Открытие Пути»
   - **Запуск от имени** — **Я** (ваш адрес)
   - **У кого есть доступ** — **Все**
4. Нажмите **Развернуть**.
5. Google попросит разрешение — **Разрешить доступ**, выберите свой аккаунт.
   Если появится экран «Google не проверил это приложение»: **Дополнительные настройки → Перейти к «Без названия» (небезопасно)**. Это ваш собственный скрипт, предупреждение стандартное для личных скриптов.
6. Скопируйте **URL веб-приложения**. Он выглядит так:
   `https://script.google.com/macros/s/AKfycb.../exec`

> ⚠️ «У кого есть доступ: Все» означает, что по этому адресу можно **отправить** данные. Читать таблицу посторонние не могут — она остаётся приватной.

## Шаг 5. Вставьте адрес в приложение

Откройте [js/config.js](js/config.js), найдите блок `submit` и вставьте адрес в кавычки:

```javascript
submit: {
  url: 'https://script.google.com/macros/s/AKfycb.../exec',
  askContact: true
},
```

Сохраните файл.

## Шаг 6. Обновите сайт

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
git add -A
git commit -m "подключил сбор ответов"
git push
```

Через минуту сайт обновится. Пройдите анкету сами — в таблице появится первая строка.

## Шаг 7 (по желанию). Уведомления прямо в Telegram

Чтобы каждый пройденный тест падал вам сообщением в Telegram:

1. Напишите в Telegram боту **@BotFather** → `/newbot` → придумайте имя и адрес бота. Он выдаст **токен** вида `7123456789:AAH...`.
2. Напишите боту **@userinfobot** — он покажет ваш числовой **ID**.
3. **Обязательно** напишите своему новому боту любое сообщение (`/start`) — иначе он не сможет вам писать первым.
4. В коде скрипта заполните две строки:
   ```javascript
   var BOT_TOKEN = '7123456789:AAH...';
   var CHAT_ID   = '123456789';
   ```
5. Сохраните и заново нажмите **Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть**.

> Токен хранится **на серверах Google**, внутри вашего скрипта. В браузер участника он не попадает и в открытый репозиторий не выкладывается. Это важно: токен в коде сайта позволил бы посторонним управлять вашим ботом.

## Шаг 8 (по желанию). Анкета прямо внутри Telegram

Приложение умеет работать как **Telegram Mini App**: человек нажимает кнопку в чате с ботом, анкета открывается внутри Telegram, и приложение **само узнаёт, кто её проходит** — имя и `@username` приходят от Telegram, вводить ничего не нужно. Поле контакта в этом случае скрывается автоматически.

Настройка:

1. В **@BotFather** отправьте `/newapp` (или `/mybots` → ваш бот → **Bot Settings → Menu Button**).
2. Выберите своего бота.
3. Укажите адрес: `https://presidenta.github.io/otkrytie-puti/`
4. Задайте название кнопки, например «Открытие Пути», и загрузите картинку 640×360.

Теперь у бота появится кнопка меню. Участник открывает бота, жмёт кнопку — анкета разворачивается внутри Telegram на весь экран.

В таблицу дополнительно попадут колонки **Telegram** (`@username`) и **Telegram ID** — числовой идентификатор. По нему вы точно знаете, кто именно проходил тест, даже если человек не написал имя.

Обычная ссылка при этом продолжает работать: вне Telegram приложение просто спрашивает контакт как раньше.

## Что попадает в таблицу

Одна строка = один пройденный тест, 25 колонок:

| Колонка | Содержимое |
|---|---|
| Дата, Время | когда прошёл |
| Язык | ru или ua |
| Имя, Telegram, Telegram ID | кто проходил |
| Согласие, Когда согласился | отметка галочки и точное время — доказательство согласия |
| Ведущий / Дополняющий вектор + баллы | психотип |
| Все векторы | баллы по всем восьми, одной строкой |
| Готовность % | индекс готовности |
| Мечта 1–3 | три ответа про достижения дословно |
| Цена мечты, Личный вклад, Уровень дохода | ответы на финальные вопросы |
| Состояние, Саботаж, Копинг, Готов отдать | расширенный профиль |
| **Все ответы** | каждый выбор по всем 20 вопросам, дословно, с номерами |

В последней колонке видно всё до единого выбора — по ней можно разбирать человека вручную.

## Что важно знать

**Согласие.** На стартовом экране стоит галочка «Даю согласие на обработку персональных данных» — без неё кнопка запуска не сработает. Рядом ссылка «Прочитать» открывает полный текст согласия. Текст лежит в языковых файлах (`agreement`), правится как любой другой текст и работает офлайн. Факт согласия и точное время попадают в таблицу отдельными колонками — это ваше доказательство, что человек согласие давал.

**Пока адрес таблицы не вставлен**, приложение ничего никуда не отправляет — галочка при этом всё равно показывается.

**Если у участника пропал интернет**, результат кладётся в очередь в его браузере и уходит сам, когда человек в следующий раз откроет страницу. Ответ не теряется.

**Поле Telegram** скрывается автоматически, если анкета открыта внутри Telegram — там имя пользователя уже известно. Убрать поле совсем: `askContact: false` в конфиге.

**Удаление данных.** Участник вправе попросить удалить свой ответ — просто удалите его строку в таблице.

## Альтернативы, если Google не подходит

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Google Таблица** ← сейчас | бесплатно, данные ваши, готовая админка | нужна разовая настройка |
| Airtable, Notion | красивее интерфейс | лимиты бесплатного тарифа |
| Свой сервер + база | полный контроль | нужен разработчик и оплата хостинга |
| Только кнопка «Скопировать отчёт» | ничего не настраивать | участник может не прислать |

Скажите, если захотите другой вариант — движок отправки универсальный, меняется только адрес.
