# ОТКРЫТИЕ ПУТИ · ВІДКРИТТЯ ШЛЯХУ · Genesis Solar Life

Веб-инструмент психологической диагностики: 20 вопросов, 8 векторов личности, результат «Ваш путь открыт».
Два языка (RU / UA) с переключением на лету. Работает офлайн, без сервера. Данные участника никуда не отправляются.

---

## Структура: где что править

| Файл | Что внутри | Когда открывать |
|---|---|---|
| `index.html` | каркас страницы, текста почти нет | меняете структуру экранов |
| `css/style.css` | **все** цвета, анимации, стили печати | меняете внешний вид |
| `js/config.js` | таймер, режим подсчёта, список языков | меняете правила игры |
| `js/content-ru.js` | **весь** русский текст: вопросы, психотипы, интерфейс | правите русский |
| `js/content-ua.js` | **весь** украинский текст | правите украинский |
| `js/script.js` | логика | меняете поведение |
| `build.ps1` | сборка одного файла | перед отправкой участникам |
| `export-questions.ps1` | выгрузка анкеты в текст | нужно показать анкету людям без кода |
| `dist/index.html` | **результат сборки** — не редактировать | это файл для участников |

Правило простое: **правите исходники, отдаёте людям `dist/index.html`.**

## Два языка

Переключатель **RU / UA** стоит в шапке. При смене языка страница не перезагружается: текущий вопрос, все расставленные приоритеты и готовый результат сохраняются — меняется только текст.

Это работает потому, что в памяти хранятся не строки, а **числа**: порядок перемешивания и номера выбранных вариантов. Текст подставляется в момент отрисовки.

**Отсюда главное правило:** в `content-ru.js` и `content-ua.js` должно быть одинаковое число вопросов, одинаковое число вариантов в каждом вопросе и одинаковые `type` на тех же местах. Иначе переключение сломается. Совпадение проверяется автоматически при загрузке — ошибки видны в консоли браузера (**F12** → Console) красным.

Добавить третий язык: скопировать `content-ru.js` → `content-xx.js`, перевести, дописать `'xx'` в `languages` в [js/config.js](js/config.js) и подключить файл в `index.html` и `build.ps1`.

## Как поменять вопрос

Откройте нужный языковой файл, найдите `id`, поправьте `title` или `text`. Поправьте **в обоих языках**.

```js
{
  id: 5,
  title: 'Новый текст вопроса…',
  options: [
    { text: 'Новая формулировка.', type: 1 },
    …
  ]
}
```

**Служебные поля вопроса:**

| Поле | Значение |
|---|---|
| `type: 1–8` | номер вектора; внутри вопроса не повторяется |
| `scored: false` | вопрос показывается и попадает в результат дословно, но баллов не даёт |
| `picks: 1` | в вопросе выбирается один вариант, а не три |

⚠️ В украинском файле используйте типографский апостроф `’`, а не прямой `'` — прямой разорвёт строку в коде.

## Как считаются баллы

Настройка `scoring` в [js/config.js](js/config.js):

| Режим | Как считает | Максимум по вектору |
|---|---|---|
| `'weighted'` ← сейчас | 1 место = 3 балла, 2 место = 2, 3 место = 1 | 51 |
| `'count'` | 1 балл за любой выбранный вариант, приоритет не важен | 17 |

Баллы дают вопросы **1–17**. Вопросы **18, 19, 20** помечены `scored: false`: они измеряют время и деньги, а не вектор мышления, поэтому идут в результат дословно, но профиль не искажают.

**Драматургия анкеты — волна, а не нарастающее давление.** Тяжёлые вопросы намеренно разведены ресурсными:

| № | Блок | Тон |
|---|---|---|
| 1–5 | разогрев: итог пути, поток, свобода, дети, точка гнева | ресурс |
| 6 | паттерн саботажа | давление |
| 7–10 | как ты действуешь в деле | ровно |
| 11 | поведение под давлением | давление |
| 12–13 | крах и образ мира | ровно |
| 14 | жёсткий trade-off (один выбор) | давление |
| 15 | достижение главной цели | ресурс · передышка |
| 16 | голос мечты / тень (один выбор) | давление |
| 17 | высота и достижения — **мечта** | ресурс |
| 18–20 | цена мечты · личная готовность · уровень свободы | финал |

Вопрос 17 стоит вплотную перед 18 намеренно: 18-й ссылается на «мечту такого масштаба, выбранную тобой только что». Если будете менять порядок — держите эту пару рядом.

Проценты в гистограмме пересчитываются от максимума автоматически — режим можно переключать в любой момент.

## Расширенный психологический профиль

Кроме векторного профиля, результат собирает четыре блока из **конкретных ответов**, а не из баллов:

| Блок результата | Собирается из | Где лежит текст |
|---|---|---|
| 3 · Состояние на сейчас | вопрос о голосе мечты + сверка с ведущим вектором | `psych.shadow` |
| 4 · Стресс-профиль и саботаж | вопрос о причине срыва + вопрос о вечере перед дедлайном | `psych.sabotage`, `psych.pressure` |
| 6 · Как ты проявляешься в проекте | ведущий вектор + вопрос о жёстком выборе | `psych.role`, `psych.tradeoff` |
| 7 · Правила безопасности | ведущий вектор | `psych.safety` |

Какие именно вопросы считаются триггерными, задано в [js/config.js](js/config.js) → `triggers` по **id**:

```js
triggers: { sabotage: 6, pressure: 11, tradeoff: 14, shadow: 16 }
```

Переставили вопросы — поправьте здесь номера, и всё соберётся заново. Движок к порядку не привязан. Если триггерный вопрос почему-то остался без ответа, его блок просто не выводится, а не ломает отчёт.

В каждом банке текстов ровно 8 записей — по одной на вектор. Полнота и зеркальность языков проверяются автоматически при загрузке.

**Тон текстов:** прямая формулировка без смягчения, но всегда с выходом. Никакого «ты особенный» и никаких предсказаний. В конце блока стоит оговорка, что это не диагноз, а пересказ собственных ответов участника.

## Как поменять цвета

Всё золото, фон и акценты — в начале [css/style.css](css/style.css), блок `:root`. Переливающийся металлик задаётся переменной `--grad-gold`: это градиент шириной 300%, который анимация `shimmer` медленно прокручивает.

## Как собрать файл для участников

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Получится `dist\index.html` — один файл ~180 КБ, работает без интернета на любом устройстве. Его можно переслать в Telegram, на почту, скинуть на флешку.

⚠️ Оба `.ps1` должны быть сохранены в **UTF-8 со знаком BOM**. Windows PowerShell 5.1 иначе читает их как ANSI и падает на кириллице.

---

## Как показать анкету людям без кода

```powershell
powershell -ExecutionPolicy Bypass -File export-questions.ps1
```

Создаст `Анкета RU.txt` и `Анкета UA.txt` — с вопросами, всеми вариантами и номерами векторов для проверки методики.

## Что умеет приложение

- **Таймер 88 → 0** чистыми цифрами, перезапуск на каждом вопросе, шкала золото → янтарь (≤40 с) → красный (≤15 с). При сворачивании вкладки отсчёт замирает.
- **Приоритеты 1 · 2 · 3** золотой, серебряной и бронзовой плашкой. Повторный клик снимает именно эту цифру. Работают клавиши 1–8.
- **Экран вопроса без подсказок** — только заголовок и карточки, как требует ТЗ.
- **Перемешивание вариантов** (Fisher–Yates) на каждом вопросе.
- **Автосохранение прогресса**: закрыл вкладку на 9-м вопросе — вернулся и продолжил с 9-го.
- **Индекс готовности** — соотношение ответов на вопросы 15 и 14.
- **Копирование отчёта** в буфер и **печать в PDF** с отдельными стилями.
- Результат переключается между языками так же, как и вопросы.
